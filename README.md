# 🌐 CryptoWeather Nexus

**CryptoWeather Nexus** is a responsive, real-time dashboard built with **Next.js**, integrating live **cryptocurrency market data**, **weather updates**, and **WebSocket notifications**. This project was developed as part of an internship to showcase skills in full-stack development, real-time data integration, and user interface design.

## 🚀 Features

- 🌦️ **Live Weather Data**  
  Get current weather updates based on user location or manual city input.

- 💹 **Real-time Cryptocurrency Info**  
  Track top cryptocurrencies with live price updates and trends.

- 🔔 **WebSocket Notifications**  
  Receive instant alerts on major market or weather changes.

- 🗂️ **Multi-page Layout**  
  Structured navigation for weather, crypto, and settings pages.

- 📱 **Responsive UI**  
  Fully mobile-friendly and optimized for all screen sizes.

- 🧠 **Redux State Management**  
  Centralized and scalable state handling across all pages.

## 🛠️ Tech Stack

| Technology    | Usage                        |
| ------------- | ---------------------------- |
| Next.js       | Framework for React and SSR  |
| React         | Frontend components and UI   |
| Redux Toolkit | Global state management      |
| WebSockets    | Real-time push notifications |
| Tailwind CSS  | Utility-first styling        |
| Axios         | API requests                 |

## 📦 Installation

1. **Clone the repository**

   `````bash
   git clone https://github.com/your-username/crypto-weather-nexus.git
   cd crypto-weather-nexus
   Install dependencies

   ````bash
    npm install


   `````

2. **Set up environment variables**

Create a .env.local file:

.env

`````
  WEATHER_API_KEY=your_openweather_api_key
  CRYPTO_API_KEY=your_crypto_api_key
  Run the development server

   ```bash
  npm run dev
  ````
Open your browser at http://localhost:3000
